# python-fullstack-data-science
**Customer Churn Prediction & Segmentation**

1. Project Overview

This project focuses on analyzing customer data and applying machine learning techniques to predict customer churn and identify customer segments.

2. Objectives

- Prepare and clean customer data
- Perform data preprocessing and feature preparation
- Predict customer churn using machine learning
- Segment customers based on their characteristics
- Evaluate model performance

3. Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

4. Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- K-Means Clustering

5. Key Techniques

- Data Preprocessing
- Feature Scaling
- Classification
- Confusion Matrix
- Precision, Recall and F1-Score
- Elbow Method
- Silhouette Score
- PCA

6. Project Files

- `Customer_Churn_Prediction.ipynb` — Complete analysis and machine learning implementation
